## What was done

Phase 3 of run 3 (`harness/pipeline/ratchet.md`): stage **11.2**, the server
half of checkers for **O-57** (other games on the same field). Decision
**0057** (how checkers sits in the game) records the calls below.

- **Rules** (`worker/games/checkers.ts`), our own engine, no dependency:
  American checkers (English draughts) on the dark squares, men forward
  only, kings one step any diagonal (no flying kings), automatic crowning,
  and a man crowned mid-jump ends its move.
- **"Jumps are required"** is a creation option (`options_json`), off by
  default. On: a capture must be taken, and a multi-jump must go on while it
  can. Off: a plain move beside a capture is allowed, and a jump may stop
  after any hop.
- **A multi-jump is walked hop by hop.** The new `waypoint` handler in
  `GameDO` judges each hop like a place: a hop the rules offer from where the
  piece is now, within reach now, and a possible walk since the last stop.
  It is stored in `carry.via_json`. One message per hop, no `setTimeout`. In
  a chess game a waypoint is still answered as an unknown message type.
- **The carry sums its legs** (lift, each waypoint, place) via the new
  `pathLengthM` in `shared/geo.ts`. A chess move keeps its old figures.
- **Endings:** the side to move with no legal move, or no pieces, loses
  (new result reason `no_moves`, "no moves left"). A fallen flag always
  loses. Resign, draw offer and abort work as for chess (decision 0050).
- **PDN** (`shared/pdn.ts`; PDN is the checkers record format, like PGN for
  chess): `GameType "21"`, `11-15`, `9x18x27`, each waypoint in the move
  comment as `via`, `SatelliteJumpsRequired`. Served as `text/plain`, named
  `satellite-checkers-<date>-<field>.pdn`.
- **The type travels everywhere:** snapshot, watcher view (carry `via`),
  report (`moves[].via`, in squares), archive, record line and game list.
  The account store (UserDO) is at schema 5, adding `game_type` to `record`
  and `game_index`. A stored type the server does not know is sent as
  stored, never as chess, and its archived file is not named as a PGN.

## Judgement calls

- **The `w` seat plays the dark pieces and moves first.** Checkers' Black
  moves first, and the clock, numbering, `1-0`, abort rule and handshake
  already assume `w` moves first. So in checkers `w` is Black.
- **Nothing is captured until the place.** A waypoint changes no square, so
  a drop or suspension mid-jump puts everything back, in line with decision
  0009 (a suspension puts a carried piece back).
- **Draws by agreement only.** The 40-move rule needs move history the
  server does not keep (the same gap as O-59, threefold repetition never
  ending a chess game); the clock bounds every game.
- **PDN as `text/plain`**: it has no registered media type.

## What was learned

- A king's multi-jump can legally end on its own origin square (for example
  `11x18x9x2x11`), and with jumps required it can be the only place offered.
  The phone must treat a tap on the origin after a waypoint as a place.
