## What was learned

**The server sends a promotion square four times.** `carryState` in the DO maps
`chess.js` `moves({verbose:true})` straight to `.to`, and chess.js enumerates a
promotion once per piece. On the board that is four dots stacked on one square and
invisible; in a count it is "4 in reach" for a single square. `carryGuidance`
dedupes. This was latent in `4.3.2`'s prompt before this session and would have
shown up the first time anyone promoted in the field.

**An author `display` rule silently defeats `hidden`.** `.promotion { display:
flex }` beat the user agent's `[hidden] { display: none }` — author origin wins
over UA origin regardless of specificity — so the picker covered the board from
the moment the game view mounted. The whole nine-move game still played, because
the driver dispatched synthetic `pointerup` events straight at the canvas and
those bypass hit-testing. **A screenshot found it; nothing else could have.** The
fix is an explicit `.promotion[hidden] { display: none }`. Anything else in
`app.css` that gains a `display` and is toggled with `hidden` needs the same.

**Clicking the board in the simulator both teleports and taps.** `attachSimDrag`
moves the player on `pointerdown`; `views/game.ts` taps on `pointerup`. For
driving a game from a script the two have to be separated — teleport via
`satchess.me.moveTo(...)` and dispatch a bare `pointerup` for the tap. A plain
`page.mouse.click` would place the piece where you already stand.

**Reaching a promotion in a driven game is nine moves.** `1.h4 g5 2.hxg5 a6
3.g6 a5 4.gxh7 a4 5.hxg8=N`. Every move is a pawn move of one or two squares, so
the carry plausibility guard (12 m/s, forgiving the summed accuracy) never binds
even when both ends are teleports — worth knowing before anyone writes a slower
driver that walks.

  `describe('suspension puts the piece back')`, both failing because the game was
  still `active`. The tests `black.close()` without awaiting it and then overwrite
  the `disconnect` timer with a past deadline; if the runtime delivers the close
