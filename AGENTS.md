# Satellite-Chess — agent instructions

The working agreement lives in **[`harness/AGENTS.md`](harness/AGENTS.md)**. Read
it before doing anything else.

This root file exists because most tools look for `AGENTS.md` here. It is a
pointer only, so there is exactly one copy of the rules to keep current.

Orient yourself in this order:

1. `harness/AGENTS.md` — the rules.
2. `harness/STATE.md` — where the project is right now.
3. The newest file in `harness/sessions/` — what the last session did and left.
4. `npm run plan` — the stage tree with statuses.
5. `harness/observations/open.md` — known problems not yet scoped.
